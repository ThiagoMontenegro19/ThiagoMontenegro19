### 🚀 Destaque

**Assistente RAG para consulta de acervo documental** · *em produção, cliente confidencial (ITA Júnior)*

- Perguntas em linguagem natural sobre um acervo de PDFs (muitos escaneados), com respostas que **citam documento e página**.
- Busca híbrida (vetorial + textual, RRF) + reranker, avaliada com um *golden set* e testes A/B de embeddings.
- Resultado: encontrar uma informação passou de **horas, dependendo de uma única pessoa**, para **segundos, para qualquer pessoa da equipe**.
